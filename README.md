# Assignment Vault 🎓

A centralized, full-stack academic repository built exclusively for our class section to easily access, search, and download assignment notes, lecture materials, and track upcoming class tests built with Vibe Coding

## Core Features
* **Class Announcement Ticker:** Real-time scrolling banner highlighting upcoming class tests (Maths, DSA, COA, App), lab exams, and submission deadlines directly at the top of the interface.
* **Instant Search & Filtering:** Quickly locate specific PDFs or notes by searching titles or subjects without page reloads.
* **Secure Admin Access:** Protected upload portal requiring a master key to publish new class materials to the live feed.
* **Cloud Infrastructure:** Reliable, fast delivery of `.pdf` and `.docx` files utilizing cloud storage and a serverless database.
* **Dark Mode UI:** Modern glassmorphism design built for readability and low eye strain during late-night study sessions.

## Tech Stack
* **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript, FontAwesome
* **Backend:** Node.js, Express.js
* **Database:** MySQL (TiDB Cloud)
* **File Management:** Multer & Cloudinary
* **Deployment:** Render
